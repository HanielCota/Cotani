# Cotani documentation

</div>

This directory contains the maintained project references. The module READMEs are the first stop for installation and
API-oriented examples; this index groups the cross-cutting guides.

## Guides

- [Architecture](architecture.md): module boundaries, lifecycle ownership and Paper/Folia thread transitions.
- [Asynchronous contracts](async-contracts.md): completion, timeout, cancellation and shutdown semantics.
- [Migration notes](migration-1.x.md): compatibility changes for the 1.x line.
- [Cookbook](ai/cotani-cookbook.md): copy-ready patterns for plugin integration.
- [AI engineering rules](ai/AGENTS-best-practices.md): how repository agents should keep changes safe.

## Generated API reference

The aggregated Javadoc is generated by `./gradlew aggregateJavadoc` and deployed by the Pages workflow. It is not
checked into the repository; the public site is linked from the root [README](../README.md).

## Verification

Documentation examples that are intended to compile live in [`docs-examples`](../docs-examples/). Run:

```bash
./gradlew check
```

When working on database-backed examples, run the Docker-backed suites separately with:

```bash
./gradlew integrationTest
```
